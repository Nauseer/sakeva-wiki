## Чаты

|                          |                                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------------- |
| сообщение                | Отправить сообщение в локальный чат. Это сообщение увидят игроки в радиусе 80 блоков от вас.         |
| !сообщение               | Отправить сообщение в глобальный чат. Это сообщение увидят все игроки сервера.                       |
| /msg (никнейм) сообщение | Отправить личное сообщение в локальный чат. Это сообщение увидит игрок, которому вы это отправляете. |
| /r сообщение             | Ответить на последнее сообщение, которое вам отправили.                                              |
