# Скины

{% hint style="info" %}
[Ознакомиться со стоимостью можно на нашем сайте.](https://shop.sakeva.net/)
{% endhint %}

***

## Информация

На нашем сервере доступна система скинов для различных предметов. Вы можете выбрать любой понравившийся вариант и установить его на свой предмет — внешний вид изменится сразу после применения.

При этом скин будет виден не только вам, но и другим игрокам.
