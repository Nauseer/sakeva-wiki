## Информация

Каждый игрок может создать собственный портал, который не требует использования блоков и поддерживает различные визуальные эффекты.

Широкий выбор эффектов — это не только возможность проявить креативность, но и способ внести реальный финансовый вклад в развитие сервера и улучшение его игровых механик!

### Шаблон подачи Тикета

Данные пункты являются **обязательными**.

1. **Координаты портала в верхнем измерении**\
   Примечание: Укажите точечные координаты по X, Y, Z.
2. **Координаты портала в адском измерении**\
   Примечание: Укажите точечные координаты по X, Y, Z.
3. **Эффект**\
   Примечание: Укажите точное [название эффекта из актуального списка](effects.md).
4. **Частота эффекта**\
   Примечание: К каждому [эффекту указаны минимальные и максимальные значения](effects.md).
